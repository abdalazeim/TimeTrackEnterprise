# TimeTrackEnterprise Android

تطبيق Flutter مصاحب لنظام TimeTrackEnterprise، مبني داخل القالب الحالي ويعيد تنفيذ وظائف **Attendance Gateway Companion 4.1.1**.

## الوظائف

- تشغيل بوابة HTTP محلية على جميع واجهات الشبكة، مع اختيار عنوان IPv4 من Ethernet أو Wi-Fi وعرض رابط الهاتف ورمز الربط.
- استقبال رموز الباركود وQR من الكاميرا أو الإدخال اليدوي، وإرسالها إلى طابور الماسحات الذي يقرأه خادم سطح المكتب عبر `/scans`.
- تسجيل حضور محلي عند توفر قائمة الطلاب، ثم مزامنة المسحات المحفوظة عند توفر الخادم.
- الربط مع تطبيق سطح المكتب من خلال `/pair`، وإرسال SMS عبر خدمة Android بعد منح صلاحية الإرسال.
- شاشة ربط الجهاز، وبوابة الموظف وولي الأمر، ولوحة الحضور والإشعارات.
- واجهة عربية/إنجليزية مع RTL/LTR.

## التشغيل

يتطلب Flutter وAndroid SDK وJDK 17.

```powershell
flutter pub get
flutter run --dart-define=APP_NAME=TimeTrackEnterprise
```

يتعرف التطبيق على واجهة الشبكة عند بدء تشغيله، ويبدأ خادم الهاتف تلقائيًا افتراضيًا. يمكن تغيير المنفذ أو إيقاف التشغيل التلقائي من إعدادات البوابة.

## توافق الخادم

يتكامل تطبيق Flutter مع واجهات Django `/api/mobile/*` لتسجيل الموظفين والأولياء، جلسات أجهزة البوابة، تنزيل قائمة التلاميذ والفترات، مزامنة المسح دون اتصال، لوحة الموظف، سجل الحضور وإشعارات ولي الأمر. يصدر المدير رموز الموظفين من الإعدادات؛ يسجل ولي الأمر برقم الطالب الوطني ذي 12 رقمًا. يتطلب الإرسال الفوري لإشعارات الدفع إعداد خدمة Firebase/FCM مستقلة؛ يعرض التطبيق الإشعارات المسجلة عند فتح البوابة.

## بناء APK

```powershell
flutter build apk --debug --dart-define=APP_NAME=TimeTrackEnterprise
```

لبناء إصدار إنتاج استخدم `tool/build_release.ps1` بعد إعداد متغيرات توقيع Android و`API_BASE_URL`. لا تحفظ ملف keystore أو كلمات المرور في Git.

الهوية الافتراضية للبناء `TimeTrackEnterprise`، والإصدار `4.1.1`. يحدّث `tool/generate_launcher_icon.ps1` أيقونات Android وملفات المعاينة، ثم ينسخ سكربت Windows الأيقونة والـAPK إلى `dist/`.
